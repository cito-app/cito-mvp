## 💡 Aprendizajes

1. **Supabase Storage es poderoso**
   - Muy fácil comparado con AWS S3
   - Políticas RLS aplicadas igual que en BD
   - Perfecto para MVPs

2. **Preview de imágenes con FileReader**
   - Patrón útil: `readAsDataURL`
   - Crear preview antes de upload
   - Mejor UX

3. **Color picker HTML5 suficiente**
   - No siempre necesitas librerías
   - HTML5 tiene muchas cosas built-in
   - Menos dependencias = mejor

4. **Estados derivados en React**
   - `hayCambios` derivado de otros estados
   - No necesita useState
   - Más limpio

5. **Modal pattern funciona bien**
   - Cambiar password en modal
   - Mejor que página separada
   - Mantiene contexto
