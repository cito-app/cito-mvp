## 💡 APRENDIZAJES CLAVE

### Técnicos
1. **react-calendar es excelente** - Accesible, personalizable, bien mantenida
2. **Scroll programático mejora UX** - useRef + scrollIntoView = magia
3. **Animaciones sutiles importan** - 300ms fadeIn hace diferencia
4. **Buffer tiempo es esencial** - 30 min previene agendamientos problemáticos
5. **Color primario consistente** - Genera identidad de marca fuerte

### Proceso
6. **Testing exhaustivo vale** - 100+ tests = 0 bugs críticos
7. **Documentar mientras desarrollas** - Ahorra tiempo al final
8. **Client components para MVP** - Más rápido que SSR para validación
9. **Commits diarios organizados** - Facilita rastreo de cambios

### Negocio
10. **Calendario visual es clave** - Usuarios mexicanos lo prefieren vs. lista
11. **90 días es suficiente** - PyMEs no planean más allá
12. **Personalización marca** - Color primario = reconocimiento
